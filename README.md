# 风云战机

《风云战机》是一款以动态气象战场为核心的原创竖屏弹幕射击游戏。

当前版本已经包含前六关的完整可玩流程：

- 鼠标、触屏和键盘操控
- 自动射击、护盾、生命和气象爆发
- 四架可选择玩家战机：“苍隼”双联脉冲、“曜光”持续聚束激光、“赤霄”高频双短束激光与“紫宸”自动区域轰炸
- 三种原创高精度敌机与多组编队
- 强风、雷区及风眼天气机制
- 关底 BOSS“积雨云母舰”
- 第二关“云海追猎”、云幕遮蔽和追猎锁定机制
- 第二关专属 BOSS“隐云母舰·蜃影”及三阶段弹幕
- 第三关“风塔回廊”、周期横风、安全航道与专属 BOSS“罡虎机”
- 第四关“电网边境”、横纵导电区、环境连锁伤害与专属 BOSS“雷狱”
- 第五关“怒海孤航”、远海岛链、横向涌浪与专属 BOSS“玄鲸”
- 第六关“山河险渡”、山野河谷、落石轰击与专属 BOSS“岚蛟”
- 独立“无尽风暴”模式，随时间提升敌群、耐久、速度、弹速和天气强度
- 无尽模式每 60 秒轮换背景、周期遭遇六类 BOSS，并保存最长生存纪录
- 原创高精度玩家战机与 BOSS 美术
- 分级概率掉落、拾取吸附与四类局内道具
- 最多储存 3 个的“倍增核心”，可主动释放 7 秒武器数量翻倍
- 护盾数值显示开关、暂停和合成音效
- 六关各自独立的主背景，以及四套后续环境预览
- 本地最高分与设置持久化

## 运行

直接双击 `index.html` 即可开始游戏。

也可以在项目目录启动一个本地服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 操作

- 移动：鼠标拖动、触屏拖动，或 `WASD` / 方向键
- 气象爆发：点击右下角按钮，或按 `空格`
- 倍增核心：点击右侧“×2”按钮，或按 `E`；苍隼扩展为四列光弹、曜光变为左右双束、赤霄由两束变四束、紫宸同时生成两个轰炸圈
- 暂停：`Esc` 或右上角暂停按钮
- 返回机库：暂停后点击“返回机库”，可从任意闯关或无尽模式中结束本次出击
- 静音：右上角声音按钮
- 设置：右上角“设”按钮，可控制是否显示护盾数值
- 战机选择：在开始界面选择“苍隼”“曜光”“赤霄”或“紫宸”，选择会保存在本地

关卡会按第一至第六关顺序解锁。解锁记录保存在本地，之后可以从开始界面直接进入任意已解锁关卡。

无尽模式无需解锁，点击开始界面的“∞ 无尽风暴”即可进入。它没有最终胜利条件，战机被击毁后结算生存时间、分数和击破的 BOSS 数量。

“苍隼”会自动发射两列脉冲光弹，适合移动中覆盖目标；“曜光”会持续攻击机头正上方最近的敌人，约 4.2 秒过热、约 1.3 秒完成主要冷却，更适合保持同轴追踪；火红色“赤霄”每 0.18 秒发射一组双短束激光，单束仅约 32 像素长，形成清晰的“biu、biu、biu”点射节奏；紫色“紫宸”每 1.55 秒自动寻找敌机最密集的位置，经过 0.3 秒锁定预警后实施一次小范围轰炸。结算后可以点击“返回机库”更换战机。

气象能量达到 100% 后可以释放气象爆发：清除敌方子弹、短暂无敌并对全屏敌人造成伤害。贴近敌方子弹进行擦弹可以更快积累能量和分数。

## 项目结构

```text
风云战机/
├─ index.html
├─ styles.css
├─ src/
│  ├─ core/          # 运行环境、Game 生命周期与主循环
│  ├─ data/          # 战机、关卡、环境和统一平衡参数
│  ├─ systems/       # 武器、战斗、关卡导演、BOSS 与天气机制
│  ├─ render/        # 背景、实体、特效与 HUD 绘制
│  ├─ services/      # 本地存档与合成音效
│  ├─ ui/            # 数据驱动的机库界面
│  └─ main.js        # 游戏启动与调试接口
├─ tests/
│  ├─ catalog.test.js
│  ├─ storage.test.js
│  ├─ smoke.js
│  └─ run-all.js
├─ assets/
│  ├─ ships/       # 游戏运行时优化素材
│  └─ source/      # 高分辨率透明母版
├─ ARCHITECTURE.md
├─ package.json
├─ README.md
└─ DEVELOPMENT_PLAN.md
```

项目当前不依赖第三方框架或网络服务，存档保存在浏览器本地。

可运行 `npm test` 或 `node tests/run-all.js` 检查配置、平衡参数、存档迁移、四架战机、六关流程以及无尽模式。新增战机与关卡的模块约定见 `ARCHITECTURE.md`。

战机与敌机素材为本项目原创生成素材。游戏会在素材未加载完成时自动使用程序化备用图形。

## 关卡背景与后续预览

在本地服务器运行时，可以使用查询参数预览十套背景：

- `?environment=skyCity`：浮空城（第一关）
- `?environment=cloudSea`：云海航路（第二关）
- `?environment=windCorridor`：风塔回廊（第三关）
- `?environment=powerGrid`：边境电网（第四关）
- `?environment=thunderCanyon`：雷鸣峡谷
- `?environment=sandstorm`：沙暴遗迹
- `?environment=polarNight`：极夜极光
- `?environment=orbitalRuins`：轨道残骸
- `?environment=oceanFront`：远海岛链（第五关）
- `?environment=riverValley`：山河峡谷（第六关）

第三关的背景以两侧风塔、双涡轮与透视安全航道建立“狭窄高速通道”的视觉记忆；第四关改用黑蓝电网、导电塔和酸黄色节点，轮廓、色相与运动语言均不复用前三关。
第五关使用滚动浪纹、岛礁与深海蓝青色调；第六关使用山野岩壁、蜿蜒河流和青绿色植被，继续保持每关视觉主题独立。
